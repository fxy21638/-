声音男女识别与变声项目 — 信号与系统知识点分析
============================================================

本项目基于 XGBoost + pyworld 实现实时声音性别识别与变声，
完整覆盖信号与系统课程的以下核心知识点。


一、采样定理（Sampling）
─────────────────────

【采样率 22050Hz】
voice_gender_gui.py  SAMPLE_RATE = 22050
语音信号的典型带宽约 8-11kHz，根据 Nyquist 采样定理，采样率需大于 2×fmax。
22050Hz > 2×11025Hz，满足无失真重建条件。

【奈奎斯特频率归一化】
main.py:177-187
  nyquist = sr / 2.0
  features["meanfreq"] = centroid / nyquist
  features["sd"] = std(centroid) / nyquist
  features["median"] = median(centroid) / nyquist
  features["Q25"] = percentile(centroid, 25) / nyquist
  features["Q75"] = percentile(centroid, 75) / nyquist
所有频谱特征除以奈奎斯特频率做归一化，约束到 [0, 1] 区间，
使特征值与具体采样率无关，便于模型泛化。

【实时块处理 — 离散时间窗化】
voice_gender_gui.py
  sd.InputStream(samplerate=22050, blocksize=2048, callback=_audio_callback)
每 2048 个采样点为一个处理块，持续时间 = 2048/22050 ≈ 93ms。
这是离散时间信号处理中"分帧"概念的实时实现。

【环形缓冲区 — 流式信号的存储】
voice_gender_gui.py:114-163  class AudioRingBuffer
固定容量 15 秒的循环缓冲区（capacity = 15 × 22050 = 330750 样本）。
写指针循环覆盖旧数据，实现 O(1) 写入和 O(n) 滑动窗口提取。

【滑动窗口提取 — 预测窗口】
voice_gender_gui.py:139-150  get_last(duration_seconds=3.0)
从环形缓冲区取最近 3 秒数据用于预测，窗口以实时采集速率向前滑动。
预测每 0.8 秒触发一次（PREDICT_INTERVAL_MS = 800）。

【全量录音存储 — 突破环形缓冲限制】
voice_gender_gui.py _audio_callback()
除写入环形缓冲区外，同时将每块采样追加到 _full_audio_chunks 列表，
停止时用 np.concatenate() 拼接完整录音，导出不受 15 秒容量限制。


二、傅里叶变换与频域分析
─────────────────────

【STFT — 短时傅里叶变换（核心）】
main.py:195-196
  stft = np.abs(librosa.stft(y, n_fft=2048))
  freqs = librosa.fft_frequencies(sr=sr, n_fft=2048)
对加窗分帧后的信号逐帧计算 DFT，取模得到幅度谱。
这是整个项目的核心变换：将 1D 时域信号 y(t) 映射为
2D 时频谱 S(t, f)，所有 18 个声学特征均基于此变换。

【FFT 共轭对称性】
main.py:179  n_bins = n_fft // 2 + 1 = 1025
实信号的傅里叶变换具有共轭对称性：X[-k] = X*[k]。
因此只需存储正频率部分（含 DC 和 Nyquist），
即 n_fft/2 + 1 = 1025 个频点。

【频谱质心 — 频率域一阶矩】
main.py:181  librosa.feature.spectral_centroid(y=y, sr=sr)
              Σ f × |S(t,f)|
  centroid = ──────────────
                Σ |S(t,f)|

加权平均频率，频谱"重心"。女声高频能量更多，质心偏高；
男声低频能量更多，质心偏低。是性别分类最重要的单一特征。

【谱熵 — 频率域信息度量】
main.py:143-151  _spectral_entropy()
将每帧功率谱归一化为概率分布 P(f) = |S(f)|² / Σ|S(f)|²，
计算 Shannon 熵 H = -Σ P(f)·log₂P(f)。
白噪声 → 功率均匀分布 → 高熵；纯音 → 功率集中 → 低熵。
用 log₂(n_bins) 做最大熵归一化（main.py:198）。

【谱平坦度 — Wiener 熵】（已从特征集移除）
main.py:192  librosa.feature.spectral_flatness(y=y)
在特征重要性分析中贡献极低且对噪声敏感，已从模型 18 特征中移除。


三、信号能量与功率
─────────────────

【RMS 能量 — 时域信号功率】
main.py VAD 检测
  rms = sqrt(mean(y²))
信号均方根 = 零均值信号的功率平方根。

GUI 端 VAD (voice_gender_gui.py PredictWorker.run):
  将音频按 100ms 分帧，以第 20 百分位为噪声基底，
  阈值 = max(noise_floor × 3, 0.0015)。
  若 RMS 超阈值帧占比 < 10% 则判定为无效语音。
  自适应阈值设计：基于噪声基底的动态阈值，适应不同环境底噪。

【峰值幅度检测】
voice_gender_gui.py
  amplitude = max(|recent_y|)
取最近 1 秒采样的绝对最大值，反映瞬时信号强度。

【峰值归一化】
main.py:574-577
  peak = max(|y_converted|)
  if peak > 1.0: y_converted = y_converted / peak
合成后的线性缩放，防止超过 [-1, 1] 范围导致削波失真。
线性缩放不改变频谱形状（保持各频率分量比例不变）。


四、统计信号处理
───────────────

【偏度 — 三阶标准化矩】
main.py:123-130  _skew()
  skew = E[((X-μ)/σ)³]
频谱质心分布的不对称性度量。正值表示分布右偏（高频能量多），
负值表示左偏（低频能量多）。

【峰度 — 四阶标准化矩】
main.py:133-140  _kurtosis()
  kurt = E[((X-μ)/σ)⁴]
频谱质心分布的"尖峰程度"。高值表示能量集中在少数频段，
低值表示能量分散。

【分位数特征】
main.py:185-189
  IQR = Q75 - Q25 → 频谱质心的四分位距，反映频谱散布程度
  Q25, Q75 → 第一和第三四分位数

【调制指数 — 变异系数】
main.py:227
  modindx = std(F0) / mean(F0)
F0 的标准差与均值之比，衡量音高变化的相对幅度，
是区分男女说话风格的重要特征。

【优势频率分析】
main.py:200-214
  mode = argmax(mean_spectrum) → 最大能量频点
  dom_freq = argmax(stft, axis=0) → 逐帧主频
  meandom, maxdom → 优势频率的统计量
  dfrange = maxdom - mindom → 优势频率的动态范围


五、基频估计（Fundamental Frequency / Pitch）
───────────────────────────────────────────

【YIN 算法 — 自相关法】
main.py:217-222
  f0 = librosa.yin(y, fmin=50, fmax=500, sr=sr)
  f0 = f0[(f0 >= 50) & (f0 <= 450)]  # 清音帧伪迹剔除
基于自相关函数的时域周期检测。搜索范围 50-500Hz
覆盖人类语音 F0 范围：男声 ~85-180Hz，女声 ~165-255Hz。
YIN 对所有帧输出估计值（包括清音帧），>450Hz 的值基本是伪迹，
施加硬性剪裁确保特征提取的清洁度。

【Harvest 算法 — 频域法】
main.py / voice_gender_gui.py (变声管线)
  f0, t = pw.harvest(y, sr, f0_floor=50, f0_ceil=500)
pyworld 的更鲁棒基频估计器，结合多分辨率分析。
配合 StoneMask 去除清音帧的 F0 假值：
  f0 = pw.stonemask(y, f0, t, sr)

【F0 特征提取】
main.py:224-227
  meanfun = mean(F0) / 1000  → 平均基频（归一化）
  minfun  = min(F0) / 1000   → 最低基频
  maxfun  = max(F0) / 1000   → 最高基频
这三个特征是性别识别的核心特征之一，归一化除以 1000 确保
与训练数据分布（meanfun ~0.06-0.24）对齐。


六、源-滤波器模型（Source-Filter Model）— 变声核心
────────────────────────────────────────────────

语音 = 声门激励（源）× 声道共振（滤波器）是语音信号处理的经典理论。

【F0 提取（源激励）】
voice_gender_gui.py ConvertWorker.run()
  f0, t = pw.harvest(y, sr, f0_floor=50, f0_ceil=500)
  f0 = pw.stonemask(y, f0, t, sr)
Harvest 算法提取基频轮廓 + StoneMask 去除清音帧误检。

【频谱包络估计（声道滤波器）】
voice_gender_gui.py ConvertWorker.run()
  sp = pw.cheaptrick(y, f0, t, sr)
CheapTrick 算法估计频谱包络，代表声道的共振特性（共振峰）。

【非周期性估计（谐波/噪声分离）】
voice_gender_gui.py ConvertWorker.run()
  ap = pw.d4c(y, f0, t, sr)
D4C 算法估计各频段的非周期成分比例（噪声/总能量）。

【F0 比例缩放 — 改变音高】
main.py:376-396  _compute_f0_ratio()
  f0_converted = _smooth_f0(f0 × f0_ratio, window=5)
F0 缩放后经两阶段平滑处理（中值滤波 + 局部线性插值），消除估计野值。
参数公式（最新）：
  男→女: target_f0 = 200 + 60×strength Hz, max_ratio = 1.80 + 0.80×strength
  女→男: target_f0 = 120 - 55×strength Hz, min_ratio = 0.65 - 0.40×strength
默认强度 0.55 时男→女比上限 2.24（100Hz 男声 → 224Hz 女声范围）。

【共振峰移位（Formant Shift）— 局部频域拉伸】
main.py:420-509  _estimate_formant_peaks() + _shift_formant_envelope()

创新点：不同于传统全局频率轴 warping，本项目采用基于共振峰检测的局部拉伸：
1. _estimate_formant_peaks():
   - log 域频谱用 scipy.signal.argrelextrema 检测峰值
   - 共振峰频段约束：F1(200-900Hz), F2(800-2400Hz), F3(2000-3500Hz), F4(3000-4800Hz)
   - 取每个频段内最高峰值作为该共振峰估计
2. _shift_formant_envelope():
   - 对每个共振峰的 ±30% 频宽区域做局部频域拉伸（np.interp 重采样）
   - 混合比: 0.50 + 0.25×strength（50-75% 拉伸谱 + 25-50% 原始谱）
   - 男→女移位 18-33%，女→男移位 10-20%
   - 若 <10% 帧检出共振峰，回退到全局 warping

设计原理：仅修改共振峰区域（声道滤波器的关键特征），保留其余频段的自然结构。
相比全局 warping，避免了拉伸非共振峰区域的噪声和伪影。
也避免了全局 warp 导致的主导频率（meandom）和频谱质心（centroid）超出训练分布。

【频谱倾斜（Spectral Tilt）— 多段非线性频率域滤波】
main.py:536-569  _apply_spectral_tilt()
男→女方向（最新参数）:
  50Hz:  0.50 - 0.22×brightness  → 深削最低频 (-50~-65%)
  220Hz: 0.60 - 0.18×brightness  → 强削低音
  550Hz: 0.92 + 0.06×brightness  → 近中性
  1500Hz: 0.98 + 0.08×brightness → 微调（避免推高meandom）
  3200Hz: 0.95 + 0.10×brightness → 微调（避免推高centroid）
  11025Hz: 0.97 + 0.06×brightness → 接近平坦

关键设计考量：1500Hz 和 3200Hz 的增益必须保守。过度增强中高频会
提升频谱质心和主导频率，使其超出训练数据分布范围（centroid>0.251），
导致模型将变声结果误判为男声。经过实验对比优化，当前参数在
"音色可感知变化"与"特征保持在训练分布内"之间取得平衡。

女→男方向:
  大幅增强 50-250Hz 低频（+35~+54%）+ 大幅削减 1.5kHz 以上高频（-20~-42%）
brightness = 0.35 + strength × 0.45，确保倾斜力度与用户设定强度一致。

【频谱混合 — 频率自适应频域插值】
main.py:572-586  _mix_with_original()
  mix_base = linspace(0.85, 0.91, n_bins)  # 展平的频段混合
  mix_ratio = mix_base + 0.06×strength + 性别偏移
  sp_out = (1 - mix_ratio) × sp_original + mix_ratio × sp_converted
混合比 85-91% 转换谱 + 9-15% 原始谱（默认强度下）。
展平的 linspace 使各频段混合一致，避免旧版"低频保守/高频激进"的频段差异。
男→女方向额外 +0.02，女→男方向额外 -0.01。

【非周期性调整 — 谐波/噪声比控制】
main.py:695-720  _adjust_aperiodicity(ap, f0_ratio, target)
根据音高变化幅度（f0_ratio 偏离 1.0 的程度）动态调整高频非周期性。
女声方向增加高频气息感（声门激励更不规则），男声方向减少。
调整量与转换强度成比例，仅在 F0>0 的浊音帧上执行。

【后处理低通滤波】
main.py:670-678  _post_process()
7.5kHz Butterworth 低通滤波（4阶），去除 WORLD 合成可能引入的高频伪影。
截止频率选择：保留语音主要频段（<7.5kHz），滤除合成算法可能产生的高频杂散。

【WORLD 合成 — 从参数重建波形】
voice_gender_gui.py ConvertWorker.run()
  y_converted = pw.synthesize(f0_converted, sp_converted, ap_converted, sr)
从 F0（源）+ 频谱包络（滤波器）+ 非周期性（噪声配比）
三个参数重建时域波形。这是分析-修改-合成的完整闭环。


七、滤波与卷积
─────────────

【F0 平滑 — 中值+线性两阶段处理】
main.py:589-614  _smooth_f0(window=5)
第一阶段（中值滤波）：对邻域内有声帧取中值
  去除孤立野值（倍频/半频错误），保留清/浊音边界。
第二阶段（局部线性插值）：有声段间隙 ≤ 6 帧（~30ms）的短断裂
  用线性插值桥接，修复 F0 估计的临时断裂。
非线性（中值）+ 线性（插值）的组合处理。

【频谱包络平滑 — 同态滤波】
main.py:680-692  _smooth_spectral_envelope()
log 域滑动平均 FIR 低通滤波 → exp 重建。
取 log → 卷积 → exp 的过程称为同态滤波。
注：经实验验证，此平滑会降低频谱熵（sp.ent），
对男→女变声有反作用，GUI 管线中已移除。仅保留在 Web 版变声管线中。

【后处理 Butterworth 低通】
main.py _post_process()
7.5kHz 截止频率，4 阶 Butterworth IIR 滤波器，
经 filtfilt 零相位滤波（正反两次，消除相位失真）。

十、频域特征空间与分类
─────────────────────

【全部 18 个特征来源于频域】
voice_clarify_train_v2.py:19-27
特征名称列表（18个特征）：
  meanfreq, sd, median, Q25, Q75, IQR, skew, kurt,
  sp.ent, mode, centroid, meanfun, minfun, maxfun,
  meandom, maxdom, dfrange, modindx
每一个特征都是时域信号经过 FFT/STFT → 频域
→ 统计聚合的结果。没有任何特征直接从时域采样值计算。
注：相比原始20特征，移除了 sfm（谱平坦度）和 mindom（最小主频），
两者在特征重要性分析中贡献极低且有噪声敏感性。

【XGBoost 分类器】
voice_clarify_train_v2.py:77-83
在 18 维频域特征空间中学习男/女非线性决策边界。
模型参数: max_depth=3, n_estimators=100, learning_rate=0.1
特征重要性: meanfun(10.2%), maxfun(8.2%), modindx(7.3%) → Top3 合计 25.7%

【训练策略 — 演员独立划分】
voice_clarify_train_v2.py
不再使用随机 80/20 按文件划分（会导致同一演员的语音出现在训练/测试集，
造成数据泄漏），而是按 RAVDESS 的 Actor ID 划分：
  训练集: Actor 1-22（男女各 11 位）→ 1320 条音频
  测试集: Actor 23(男) + Actor 24(女) → 264 条音频
  模型性能: 测试集 79.2%（男 61.7%, 女 96.7%），全量 95.5%
这种划分方式是语音识别研究的标准做法，确保测试集演员从未被模型见过。

【分段预测 — 长音频男女声占比】
main.py:239-286  predict_gender_segmented()
混合策略：
  全局预测: 完整音频提取特征 → 性别判断（匹配训练流程）
  分段投票: 2.5s 窗口 + 0.8s 步长滑动 → 各段独立预测 → 统计占比
  置信度 <55% 的段标记为 unknown
应用在文件上传测试中显示男女声百分比，实时麦克风不显示（始终同一说话人）。

【F0 特征提取改进】

librosa.yin 对所有帧（包括清音帧）输出 F0 估计，

施加 f0[(f0>=50) & (f0<=450)] 硬性剪裁，确保 maxfun 不受伪迹污染。

训练数据：

1320条语音（660男+660女），演员独立划分（Actor 1-22训练，23-24测试）
模型：XGBoost (max_depth=3, n_estimators=100, learning_rate=0.1)
测试集准确率: 79.2%（男 61.7%, 女 96.7%），全量准确率: 95.5%

变声性能：
女→男: ~100% 成功率（F0降低 + 削高频 + 增强低频）
男→女: ~50-60% 成功率（需大幅提升F0 + 共振峰移位，极端频谱特征难以完全消除）
男→女变声的根本限制：当原始音频的频谱熵（sp.ent）远低于训练范围
（<0.5 vs 训练最低 0.739），信号处理无法将特征恢复到训练分布内。
这是训练数据多样性的限制，非代码缺陷。
