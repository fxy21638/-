信号与系统课程大作业 — 声音男女识别项目 知识点分析
============================================================

本项目基于 XGBoost + pyworld 实现实时声音性别识别与变声，
完整覆盖信号与系统课程的以下核心知识点。


一、采样定理（Sampling）
─────────────────────

【采样率 22050Hz】
voice_gender_gui.py:308  SAMPLE_RATE = 22050
语音信号的典型带宽约 8-11kHz，根据 Nyquist 采样定理，采样率需大于 2×fmax。
22050Hz > 2×11025Hz，满足无失真重建条件。

【奈奎斯特频率归一化】
main.py:177-187
  nyquist = sr / 2.0
  features["meanfreq"] = centroid / nyquist
  features["sd"] = std(centroid) / nyquist
  features["median"] = median(centroid) / nyquist
  features["Q25"] = percentile(centroid, 25) / nyquist
  features["Q75"] = percentile(centroid, 75) / nyquist
所有频谱特征除以奈奎斯特频率做归一化，约束到 [0, 1] 区间，
使特征值与具体采样率无关，便于模型泛化。

【实时块处理 — 离散时间窗化】
voice_gender_gui.py:549-555
  sd.InputStream(samplerate=22050, blocksize=2048, callback=_audio_callback)
每 2048 个采样点为一个处理块，持续时间 = 2048/22050 ≈ 93ms。
这是离散时间信号处理中"分帧"概念的实时实现。

【环形缓冲区 — 流式信号的存储】
voice_gender_gui.py:113-162  class AudioRingBuffer
固定容量 15 秒的循环缓冲区（capacity = 15 × 22050 = 330750 样本）。
写指针循环覆盖旧数据，实现 O(1) 写入和 O(n) 滑动窗口提取。

【滑动窗口提取】
voice_gender_gui.py:139-150  get_last(duration_seconds=5.0)
从环形缓冲区取最近 5 秒数据用于预测，窗口以实时采集速率向前滑动。
预测每 2 秒触发一次（PREDICT_INTERVAL_MS = 2000），
形成 0.5Hz 的下采样预测流。


二、傅里叶变换与频域分析
─────────────────────

【STFT — 短时傅里叶变换（核心）】
main.py:195-196
  stft = np.abs(librosa.stft(y, n_fft=2048))
  freqs = librosa.fft_frequencies(sr=sr, n_fft=2048)
对加窗分帧后的信号逐帧计算 DFT，取模得到幅度谱。
这是整个项目的核心变换：将 1D 时域信号 y(t) 映射为
2D 时频谱 S(t, f)，所有 20 个声学特征均基于此变换。

【FFT 共轭对称性】
main.py:179  n_bins = n_fft // 2 + 1 = 1025
实信号的傅里叶变换具有共轭对称性：X[-k] = X*[k]。
因此只需存储正频率部分（含 DC 和 Nyquist），
即 n_fft/2 + 1 = 1025 个频点。

【频谱质心 — 频率域一阶矩】
main.py:181  librosa.feature.spectral_centroid(y=y, sr=sr)
              Σ f × |S(t,f)|
  centroid = ──────────────
                Σ |S(t,f)|

加权平均频率，频谱"重心"。女声高频能量更多，质心偏高；
男声低频能量更多，质心偏低。是性别分类最重要的单一特征。

【谱熵 — 频率域信息度量】
main.py:143-151  _spectral_entropy()
将每帧功率谱归一化为概率分布 P(f) = |S(f)|² / Σ|S(f)|²，
计算 Shannon 熵 H = -Σ P(f)·log₂P(f)。
白噪声 → 功率均匀分布 → 高熵；纯音 → 功率集中 → 低熵。
用 log₂(n_bins) 做最大熵归一化（main.py:198）。

【谱平坦度 — Wiener 熵】
main.py:192  librosa.feature.spectral_flatness(y=y)
               (∏|S(f)|)^(1/N)
  flatness = ─────────────────
                (1/N)Σ|S(f)|

几何平均与算术平均之比，衡量信号的"调性 vs 噪声性"。


三、信号能量与功率
─────────────────

【RMS 能量 — 时域信号功率】
main.py:403-411  _detect_voice_activity()
  rms = sqrt(mean(y²))
信号均方根 = 零均值信号的功率平方根。阈值 0.012 区分
人声与静音/背景噪声，用作语音活动检测（VAD）。

【峰值幅度检测】
voice_gender_gui.py:506
  amplitude = max(|recent_y|)
取最近 1 秒采样的绝对最大值，反映瞬时信号强度。

【峰值归一化】
main.py:574-577
  peak = max(|y_converted|)
  if peak > 1.0: y_converted = y_converted / peak
合成后的线性缩放，防止超过 [-1, 1] 范围导致削波失真。
线性缩放不改变频谱形状（保持各频率分量比例不变）。


四、统计信号处理
───────────────

【偏度 — 三阶标准化矩】
main.py:123-130  _skew()
  skew = E[((X-μ)/σ)³]
频谱质心分布的不对称性度量。正值表示分布右偏（高频能量多），
负值表示左偏（低频能量多）。

【峰度 — 四阶标准化矩】
main.py:133-140  _kurtosis()
  kurt = E[((X-μ)/σ)⁴]
频谱质心分布的"尖峰程度"。高值表示能量集中在少数频段，
低值表示能量分散。

【分位数特征】
main.py:185-189
  IQR = Q75 - Q25 → 频谱质心的四分位距，反映频谱散布程度
  Q25, Q75 → 第一和第三四分位数

【调制指数 — 变异系数】
main.py:227
  modindx = std(F0) / mean(F0)
F0 的标准差与均值之比，衡量音高变化的相对幅度，
是区分男女说话风格的重要特征。

【优势频率分析】
main.py:200-214
  mode = argmax(mean_spectrum) → 最大能量频点
  dom_freq = argmax(stft, axis=0) → 逐帧主频
  meandom, mindom, maxdom → 优势频率的统计量
  dfrange = maxdom - mindom → 优势频率的动态范围


五、基频估计（Fundamental Frequency / Pitch）
───────────────────────────────────────────

【YIN 算法 — 自相关法】
main.py:217-220
  f0 = librosa.yin(y, fmin=50, fmax=500, sr=sr)
基于自相关函数的时域周期检测。搜索范围 50-500Hz
覆盖人类语音 F0 范围：男声 ~85-180Hz，女声 ~165-255Hz。

【Harvest 算法 — 频域法】
main.py:555 / voice_gender_gui.py:271
  f0, t = pw.harvest(y, sr, f0_floor=50, f0_ceil=500)
pyworld 的更鲁棒基频估计器，结合多分辨率分析。
配合 StoneMask 去除清音帧的 F0 假值：
  f0 = pw.stonemask(y, f0, t, sr)  (main.py:556)

【F0 特征提取】
main.py:224-227
  meanfun = mean(F0) / 1000  → 平均基频（归一化）
  minfun  = min(F0) / 1000   → 最低基频
  maxfun  = max(F0) / 1000   → 最高基频
这三个特征是性别识别的核心特征之一。


六、源-滤波器模型（Source-Filter Model）— 变声核心
────────────────────────────────────────────────

语音 = 声门激励（源）× 声道共振（滤波器）是语音信号处理的经典理论。

【F0 提取（源激励）】
voice_gender_gui.py:271-272
  f0, t = pw.harvest(y, sr, f0_floor=50, f0_ceil=500)
  f0 = pw.stonemask(y, f0, t, sr)
Harvest 算法提取基频轮廓 + StoneMask 去除清音帧误检。

【频谱包络估计（声道滤波器）】
voice_gender_gui.py:273
  sp = pw.cheaptrick(y, f0, t, sr)
CheapTrick 算法估计频谱包络，代表声道的共振特性（共振峰）。

【非周期性估计（谐波/噪声分离）】
voice_gender_gui.py:274
  ap = pw.d4c(y, f0, t, sr)
D4C 算法估计各频段的非周期成分比例（噪声/总能量）。

【F0 比例缩放 — 改变音高】
voice_gender_gui.py:281
  f0_converted = f0 × f0_ratio
升高 F0 → 女声；降低 F0 → 男声。
f0_ratio 由 _compute_f0_ratio() 根据目标性别和强度计算。

【共振峰频移（Formant Warping）】
main.py:344-353  _warp_spectral_envelope()
对频谱包络的频率轴做拉伸/压缩：
  src_freqs = freqs / factor
  warped = interp(freqs, src_freqs, sp)
频率轴缩放改变了共振峰位置，从而改变音色（元音品质）。

【频谱倾斜（Spectral Tilt）】
main.py:356-366  _apply_spectral_tilt()
对频谱包络施加频率相关增益（高频增强 → 女声明亮；高频衰减 → 男声低沉）:
  sp = sp × tilt(freq)
本质是一个频率域的线性滤波器。

【频谱混合 — 频域插值】
main.py:369-374  _mix_with_original()
  sp_out = (1-mix) × sp_original + mix × sp_converted
在频域做线性插值，控制变声强度。属于频域信号的线性组合。

【WORLD 合成 — 从参数重建波形】
voice_gender_gui.py:288
  y_converted = pw.synthesize(f0_converted, sp_converted, ap, sr)
从 F0（源）+ 频谱包络（滤波器）+ 非周期性（噪声配比）
三个参数重建时域波形。这是分析-修改-合成的完整闭环。


七、滤波与卷积
─────────────

【卷积平滑（FIR 低通滤波器）】
main.py:395-400  _smooth_spectral_envelope()
  kernel = [1/5, 1/5, 1/5, 1/5, 1/5]   （矩形窗 FIR）
  smoothed[idx] = np.convolve(log_sp[idx], kernel, mode='same')
  return exp(smoothed)
在 log 域做同态滤波：log → 卷积平滑 → exp。
五点滑动平均 FIR 低通，消除频谱包络的快速起伏，
保留宽共振峰结构。属于线性时不变（LTI）滤波。

【中值滤波（非线性滤波）】
main.py:377-389  _smooth_f0()
  smoothed[idx] = median(voiced_f0[neighborhood])
F0 轮廓的中值滤波。与线性滤波器不同，中值滤波是非线性的，
可以有效去除 F0 估计中的倍频/半频错误（冲击性野值），
同时保留清/浊音边界的突变（边缘保持特性）。


八、信号重构与预处理
───────────────────

【最小长度填充】
main.py:154-163  _ensure_min_duration()
  y = pad(y, (pad_left, pad_right), mode='edge')
对不足 1.2 秒的音频做对称边缘填充（重复边界值）。
相比零填充，edge 模式不会在边界引入人为的频谱跳变。

【WAV 编码 — 采样量化的直接体现】
voice_clarify.html:374-410  _encodeWAV()
手动构造 RIFF/WAV 文件的二进制结构：
  - 采样率写入 DataView (uint32)
  - 声道数写入 (uint16)
  - Float32 → Int16 PCM 量化：s = clamp(x, -1, 1) × 32767
体现了模拟→数字转换的最后一步：量化。

十、频域特征空间与分类
─────────────────────

【全部 20 个特征来源于频域】
voice_clarify_train.py:13-14
特征名称列表（按训练数据 CSV 列顺序）：
  meanfreq, sd, median, Q25, Q75, IQR, skew, kurt,
  sp.ent, sfm, mode, centroid, meanfun, minfun, maxfun,
  meandom, mindom, maxdom, dfrange, modindx
每一个特征都是时域信号经过 FFT/STFT → 频域
→ 统计聚合的结果。没有任何特征直接从时域采样值计算。

【XGBoost 分类器】
voice_clarify_train.py:16-42
在 20 维频域特征空间中学习男/女非线性决策边界。
模型从训练数据中自动发现性别区分度高的特征组合
（如 meanfun + IQR + sp.ent 组合）。
